JakinsCraft ESP Cam Setup

Set up a doorbell cam over Bluetooth. Power the camera on, its flash blinks once a second while it waits for this app (2 minutes), then tap Find camera.

Camera

Not connected.

Settings

Leave blank to keep the password already stored in the camera.
Digits with country code. Blank means the server default. The server only delivers to numbers on its allowlist.
Advanced: server and token
Slide all the way to the right to save these details and lock them in the camera. A locked camera skips setup on later boots and goes straight to its photo. To reopen setup, hold the setup button (GPIO 14 to GND) while powering the camera on.
